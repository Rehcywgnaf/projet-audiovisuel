# Règles de Validation SAPAV

## Formats de Fichiers
- Formats supportés : DOC, DOCX, PDF, ODT
- Taille maximale : 10MB
- Encodage : UTF-8

## Métadonnées Requises
- Titre (3-100 caractères)
- Auteur (présence obligatoire)
- Version (format: X.Y.Z)
- Projet associé (référence valide)

## Validations Spécifiques
1. Documents Projet
   - Structure conforme au template
   - Sections requises présentes
   - Cohérence des données

2. Médias
   - Résolution minimale
   - Format d'export
   - Métadonnées techniques

## Règles Avancées
- Validation croisée avec historique
- Détection des doublons
- Vérification des liens
