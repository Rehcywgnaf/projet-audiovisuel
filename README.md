# SAPAV (Soutien Appel à Projet AudioVisuel)

## Vue d'ensemble
SAPAV est une plateforme innovante dédiée au soutien et à l'accompagnement des projets audiovisuels dans leur recherche de financements.

[Documentation complète disponible ici](/docs/project/overview.md)

### Composants Principaux
1. **Système RSS-IA**
   - Veille automatisée des opportunités
   - [Documentation détaillée](/docs/project/architecture/core.md#rss-ia)

2. **AIEnhancedEditor**
   - Génération assistée de contenu
   - [Documentation détaillée](/docs/project/architecture/ai-service.md)

3. **DocumentManager**
   - Gestion versions, commentaires
   - [Documentation détaillée](/docs/project/architecture/core.md#document-manager)
