## Roadmap

### Service AO - Évolutions Prévues

#### Amélioration de la catégorisation
- Extension des catégories de tags pour couvrir plus de spécificités du domaine audiovisuel
- Ajout de tags pour les équipements spécifiques
- Tags pour les contraintes techniques particulières
- Catégorisation par type de production

#### Optimisation des seuils
- Affinage des seuils de budget basé sur les retours d'expérience
- Ajustement des niveaux d'urgence selon les types de projets
- Personnalisation possible des seuils par utilisateur

#### Détection des clients
- Enrichissement des patterns de détection client
- Base de données des clients connus
- Historique des interactions précédentes
- Scoring automatique basé sur l'historique
